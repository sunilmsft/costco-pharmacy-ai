Slide 3 · Different Priorities, Different Experiences

about 60 seconds

A guided experience can take different forms / depending on what the organization is trying to improve. //

I've used three illustrative directions here: / growth, member value, and operational efficiency. //

If the priority is growth, / one way this experience could contribute / is by helping Costco Pharmacy acquire and retain more prescriptions / by making it easier for members to discover the right offering, begin the journey, / and successfully move through it. //

If the priority is member value, / the experience could make pharmacy journeys easier to understand and complete, / reducing effort and increasing confidence along the way. //

And if the priority is operational efficiency, / the experience could guide members through needs appropriate for self-service, / carry their context forward, / and connect them to a pharmacist when their expertise is needed. //

These directions can overlap, / and the starting point does not lock the experience into one path permanently. //

For this concept, / I used Member Value as the illustrative starting priority. //

That is not an assumption about Costco Pharmacy's actual priority. / It simply gave me a practical way to make the concept tangible / from the member's point of view.

Slide 4 · Trust and Responsible AI

90–120 seconds

As we think about how this experience could take shape, / trust and Responsible AI need to be built in from the start. //

That matters even more in pharmacy, / where medicines and clinical support come with important regulatory, clinical, privacy, and operational requirements. //

Responsible AI was one of my focus areas at Microsoft, / so I naturally think about safety and accountability / across how an AI-enabled experience is designed, deployed, and used. //

For this concept, I translated those principles into three practical guardrails. //

First, clear boundaries — / so the experience supports members / while clinical judgment stays with the pharmacist. //

Second, responsible use of context — / using approved information under defined rules, / with clear consent and member control. //

And third, intentional human support — / when the experience reaches a boundary, / it connects the member to the right help / and carries useful context forward. //

Those principles are visible in the prototype. / I’ll point out one safety moment when we get there, / before moving into the two member journeys.

Slide 5 · Validated Evolution

2–3 minutes

The approach moves from left to right. / We set direction, / then grow from Guide, / to Assist, / to Anticipate, / validating each stage as we go. //

To make that tangible, / I'll use travel preparation as one example. //

Costco already supports this need through travel immunization information / and a travel medicine consultation offering. //

So the question becomes: //

Could a more guided travel-preparation journey help members get a useful answer, / reach the right next step, / and do so with less effort?

To understand whether the experience is improving member value, / we could look at measures such as Helpful Response Rate, completion, and effort / compared with the current experience. //

Guide

At Guide, / the experience clarifies the need / and routes the member to the right information, workflow, or person — / without performing the task. //

For example: //

I'm traveling to India at the end of August. / What should I do to get ready?

The experience guides them toward the appropriate travel medicine information or support. //

Assist

At Assist, / the experience carries approved context into the workflow, / reduces repeated effort, / and lets the member review and confirm key actions. //

In the travel example, / that might mean connecting destination and timing / to relevant services, / surfacing an appointment, / and confirming the next step. //

Anticipate

At Anticipate, / the experience connects earlier signals / to a relevant prompt or action before the member initiates it. / This would require deeper integration, broader permissions, / and substantial validation, / so it is not demonstrated today.
